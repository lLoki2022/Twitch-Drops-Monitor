# 📦 Twitch Drops Monitor

**Twitch Drops Monitor** — это браузерное расширение для автоматического отслеживания, фарма и сбора **Twitch Drops** и **Channel Points** без необходимости постоянно держать стрим открытым.

Расширение автоматически находит активные кампании, переключает стримы, отслеживает прогресс и уведомляет пользователя о событиях.

---

## 🚀 Возможности

- ✅ Автоматическое отслеживание Twitch Drops  
- ✅ Авто-сбор дропов
- ✅ Авто-сбор монет
- ✅ Авто-фарм дропов 
- ✅ Переключение стримеров с активными дропами  
- ✅ Поддержка нескольких игр одновременно  
- ✅ Telegram-уведомления  
- ✅ Browser-уведомления и звуки  
- ✅ История полученных дропов

## 🧠 Как это работает

1. Расширение проверяет активные **Drop** на Twitch  
2. Определяет доступные игры и стримеров с дропами  
3. Эмулирует активный просмотр
4. Отслеживает прогресс дропа в реальном времени  
5. Автоматически получает награды и поинты  
6. Уведомляет пользователя о событиях  

⚠️ **Логины и пароли Twitch не требуются** — используется текущая сессия браузера.

---

## 🔐 Безопасность

- Расширение **не хранит пароли**
- Не передает данные третьим лицам
- Использует только Twitch API
- Все данные хранятся локально в браузере

---

## 📥 Установка

### Ручная установка (Chrome / Chromium)

1. Скачайте репозиторий или архив  
2. Распакуйте папку с расширением  
3. Перейдите в `chrome://extensions`  
4. Включите **Режим разработчика**  
5. Нажмите **Загрузить распакованное расширение**  
6. Выберите папку с проектом  

---

## ⚙️ Требования

- Google Chrome / Chromium-based браузер  
- Авторизация в Twitch в браузере  
- Аккаунт Twitch с активными Drops
